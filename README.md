# sachkov-stack

Рабочий сетап для разработки с ИИ-агентами: один канон, тонкие адаптеры рантаймов,
механические гейты вместо обещаний в промпте. Совместим с **Claude Code** и **Codex CLI**.

**Этот репозиторий генерируется** из приватного исходника командой `export-stack`. Правки,
сделанные здесь руками, будут затёрты следующей выгрузкой.

## Из чего состоит

| Слой | Что даёт |
|---|---|
| `global/` | ядро поведения агента плюс секции под каждый рантайм |
| `project/` | шаблон харнеса проекта: нейтральные гейты, правила по путям, обвязка обоих рантаймов |
| `stacks/` | оверлеи под стек: dotnet, node, next, python, go, web, content |
| `bin/` | CLI: развернуть харнес, показать дрейф, обновить, пройтись по всем проектам |
| `brain-template/` | скелет персональной базы знаний |
| `skills/` | портируемые скиллы |

## Идея

1. **Три уровня, не один.** Личный оркестратор в `~/.claude` и `~/.codex`, версионированный
   пакет, полный харнес внутри каждого репозитория. Проектный слой всегда перекрывает
   глобальный.
2. **Канон один и нейтральный.** `AGENTS.md` в корне репозитория читают все агенты. Codex
   нативно, Claude через мост `CLAUDE.md` с `@AGENTS.md`.
3. **Гейт это скрипт, а не абзац.** Всё, что можно проверить машиной, лежит в
   `.harness/gates/` и подключено к обоим рантаймам. Разница между ними сведена к единице
   таймаута: Claude считает в миллисекундах, Codex в секундах.
4. **Правила приходят по пути файла.** Правило с `paths:` во фронтматтере подставляется в
   контекст, когда агент трогает подходящий файл, один раз за сессию. Ни один рантайм не
   умеет этого сам.
5. **Дрейф считается.** `.harness/harness.lock` держит по два хеша на файл, поэтому
   обновление пакета не затирает локальные правки и не притворяется, что их нет.

## Установка

```bash
git clone https://github.com/KirillSachkov/sachkov-stack && cd sachkov-stack

./install.sh global                       # глобальный канон в оба рантайма
./install.sh skills                       # портируемые скиллы
./install.sh brain ~/dev/brain            # скелет базы знаний
./install.sh project ~/dev/projects/app --stack node --base-branch main
```

Дальше в проекте:

```bash
python3 bin/harness diff   ~/dev/projects/app    # что разошлось с пакетом
python3 bin/harness update ~/dev/projects/app    # подтянуть новую версию пакета
```

Мозг находится по маркерам (`AGENTS.md` + `memory/` + `skills/`), а не по имени каталога.
Путь задаётся переменной `AGENT_BRAIN`, иначе перебираются `~/dev/brain` и `~/brain`.
