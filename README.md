# sachkov-stack

Мой рабочий сетап для разработки с AI-агентами — в виде, который можно развернуть у себя
за несколько минут и без внешних привязок: никаких серверов, трекеров и платных сервисов.
Три слоя: методология агента (глобальный конфиг + хуки), персональная база знаний
(«мозг») и портируемые скиллы. Всё совместимо с **Claude Code** и **Codex CLI**.

## Из чего состоит

| Слой | Что дает |
|---|---|
| [global-config](global-config) | Поведение агента: думать до кода, решать ровно поставленную задачу, проверять инструментами, не памятью. Плюс хуки, которые переживают compaction. |
| [brain-template](brain-template) | Скелет «мозга» — git-репозитория долговременной памяти: `memory/`, `wiki/`, `tasks/`, реестр скиллов. |
| [skills](skills) | Портируемые скиллы: правила кодинга, пайплайн файловых задач, харнес проекта, формулировка промптов, ведение мозга. |

## Установка

```bash
git clone https://github.com/KirillSachkov/sachkov-stack && cd sachkov-stack

./install.sh all              # все скиллы в Claude Code + Codex
./install.sh caveman --claude # один скилл в один рантайм
./install.sh config           # CLAUDE.md/AGENTS.md + хуки (плейсхолдеры <...> — заменить!)
./install.sh brain ~/Work/brain   # создать мозг из шаблона (git init + первый коммит)
```

Существующие файлы бэкапятся с таймстампом. Для хуков нужен `jq`
(`brew install jq` / `sudo apt install jq`); блоки `env` и `hooks` из
[settings.example.json](global-config/settings.example.json) переносятся в
`~/.claude/settings.json` вручную.

## Глобальный конфиг

Методология одна на все рантаймы и живет в одном файле:
[AGENTS.md](global-config/AGENTS.md) — источник правды (Codex читает его нативно),
[CLAUDE.md](global-config/CLAUDE.md) — тонкий мост для Claude Code через `@AGENTS.md`.
Никакого дублирования и ручной синхронизации двух копий.

Хуки решают главную боль длинных сессий — compaction вытесняет директивы из контекста:

- [brain-anchor.sh](global-config/hooks/brain-anchor.sh) — SessionStart на
  `startup|resume|compact`: реинжектит якорь мозга после каждого сжатия и показывает
  очередь задач.
- [brain-reminder.sh](global-config/hooks/brain-reminder.sh) — UserPromptSubmit:
  короткое напоминание каждый N-й промпт (настраивается, молчит в worktree).

## Мозг

Персональная память агента — обычный git-репозиторий, который агент читает в начале
сессии и пополняет после работы. Правила — в
[brain-template/AGENTS.md](brain-template/AGENTS.md); ключевые:

- мозг — высшая авторитетность: расходится с предположением агента — прав мозг;
- `memory/` — стабильный канон (профиль, проекты, правила), `wiki/` — синтезированные
  знания с `[[wikilinks]]`, `tasks/` — inbox → active → done;
- живое состояние задачи никогда не дублируется в двух местах: есть трекер у проекта —
  задача живет там.

## Скиллы

### Методология разработки

- [karpathy-guidelines](skills/karpathy-guidelines) — поведенческие правила кодинга
  (по Andrej Karpathy, MIT): думать до кода, простота, хирургические изменения,
  проверяемый критерий готовности.
- [coding-task-pipeline](skills/coding-task-pipeline) — сквозной контракт файловой
  задачи: research → план → реализация → независимое ревью → тесты → верификация,
  с evals в комплекте.
- [project-harness-bootstrap](skills/project-harness-bootstrap) — постановка агентского
  харнеса в проектном репо: интервью владельца, канон, адаптер пайплайна, гейты.
- [prompt-library](skills/prompt-library) — 52 паттерна формулировки задач по фазам
  SDLC: outcome вместо шагов, самопроверка, референс, измеримая цель.

### Мозг и знания

- [llm-wiki](skills/llm-wiki) — ведение interlinked-wiki по паттерну Карпатого:
  компилируй знания один раз, не переоткрывай их каждым запросом.
- [brain-capture](skills/brain-capture) — захват задачи/заметки/знания в мозг из любого
  каталога, с безопасным multi-writer синком.
- [brain-task-management](skills/brain-task-management) — жизненный цикл задач мозга:
  разрешение дат инструментом, маршрутизация в трекеры, verify перед закрытием.

### Общение

- [caveman](skills/caveman) — режим экономии токенов: сжимает стиль, не точность;
  код и команды остаются byte-exact.

## Совместимость

| Рантайм | Скиллы | Конфиг |
|---|---|---|
| Claude Code | `~/.claude/skills/` | `~/.claude/CLAUDE.md` (@AGENTS.md) + хуки |
| Codex CLI | `~/.codex/skills/` | `~/.codex/AGENTS.md` |

У каждого скилла есть `agents/openai.yaml` (метаданные для Codex) и секция
runtime adapters: тело скилла нейтрально к рантайму, специфика (имена инструментов
`Bash` ↔ `terminal`) вынесена отдельно.
