# Фронтенд: порядок работы

Веб-API меняются быстро, а веса модели несут устаревшие паттерны. Поэтому для любой
нетривиальной задачи по HTML, CSS, клиентскому JS, React, Vue, Svelte, Electron renderer,
UI или UX первым идёт `modern-web-guidance`, и только потом код.

Дальше маршрут по намерению, а не всё сразу:

| Намерение | Скилл |
|---|---|
| новый интерфейс, компонент, визуальное направление | `frontend-design` |
| редизайн существующего продукта или страницы | `redesign-existing-projects` |
| реализация, доводка, визуальное ревью UI | `impeccable` (прогон `critique`, затем `polish`) |
| после реализации | `web-design-guidelines` |
| алгоритмическая производительность | `complexity-optimizer` |

После реализации проверь отрендеренный интерфейс через Playwright и скриншоты на релевантных
состояниях и ширинах. Скриншоты складывай в `screenshots/`, не в корень репозитория.

Figma как источник дизайна означает установленные Figma-скиллы и их обязательные
пререквизиты.

Правки только текста полный визуальный конвейер не требуют.
