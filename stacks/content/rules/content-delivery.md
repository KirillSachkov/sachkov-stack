# Контент: как доставляется

Решение владельца 2026-07-22, действует для всех агентов.

- **Коммит прямо в основную ветку, однопоточно.** Доски Excalidraw, их TS-модули, код
  инструментов сборки досок, страницы вики, тексты курса и проза идут в main без
  feature-веток, worktree, мержей и церемонии независимого ревью. Владелец работает по таким
  проектам в одну нитку и сам смотрит визуал.
- **Задача агента это верификация, а не ревью-ритуал:** компилируется, тесты проходят, QA
  чист, визуальных дефектов нет (перекрытия, зачёркивания, обрезка).
- Полный конвейер с worktree и независимым ревью остаётся для продуктового кода.

# Артефакт, который владелец правил руками, не перезаписывается молча

Правки поверх работы агента сохраняются обязательно.

- Для досок Excalidraw: выгрузка в хранилище отказывается перезаписать существующий файл без
  явного `--force`. Пока идёт итерация по дизайну, показывай PNG-превью и не трогай хранилище.
- Перед тем как продавить устоявшееся изменение, сначала перенеси его ручные добавления
  вперёд: распакуй живую сцену, сравни идентификаторы элементов со свежей компиляцией,
  сохрани его добавления, файлы и блок-ссылки, и только потом `--force`.
- Тот же принцип для любого регенерируемого артефакта, который он правит руками.
