# Skills Registry — единый индекс скиллов

> **Один источник правды.** Что за скилл, где лежит, когда применять.
> Кросс-проектные скиллы живут здесь, в `skills/<name>/`; в рантаймы
> (`~/.claude/skills`, `~/.codex/skills`) они попадают установкой из стека
> или симлинком. Проектные скиллы остаются в репо своего проекта.

## Правила

- Формат — agentskills.io: папка со `SKILL.md`, frontmatter `name` + `description`.
- `description` начинается с «Use when …» и содержит границы применения.
- Тело скилла — нейтральное ядро без имен рантайм-специфичных тулов; специфику
  рантайма выноси в короткую секцию «Runtime adapters».
- Новый скилл → папка + строка в таблице ниже. Скилл без строки в реестре не существует.

## Скиллы

| Skill | Назначение |
|---|---|
| `karpathy-guidelines` | поведенческие правила кодинга: думать → просто → хирургически → от цели |
| `coding-task-pipeline` | контракт файловых задач: изоляция, гейты, независимое ревью |
| `project-harness-bootstrap` | постановка агентского харнеса в новом проектном репо |
| `prompt-library` | паттерны формулировки задач для агента |
| `llm-wiki` | ведение синтезированной wiki в мозге |
| `brain-capture` | быстрый захват задачи/заметки в мозг из любого каталога |
| `brain-task-management` | жизненный цикл задач мозга: inbox → active → done |
| `caveman` | опциональный режим экономии токенов в чате |
