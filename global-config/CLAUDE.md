# Claude Code — специфика рантайма

- Скиллы запускаются Skill-тулом; список — в системном списке скиллов сессии.
  Правило из AGENTS.md действует: подходит скилл — запусти, не работай «по памяти».
- Хуки этого стека (см. `settings.example.json`): `brain-anchor.sh` реинжектит якорь
  мозга на старте сессии и после compaction; `brain-reminder.sh` напоминает про мозг
  каждый N-й промпт. Директивы обязаны переживать сжатие контекста.
- Проверка фактов: файлы — Read/Grep, команды — Bash, библиотеки — WebSearch/WebFetch
  или context7, если подключен.
