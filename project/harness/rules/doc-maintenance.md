# Документация

- Правь существующий документ вместо создания дубля рядом.
- Канон репозитория один: корневой `AGENTS.md`. `CLAUDE.md` это мост, содержательных правил
  в нём не бывает.
- Прозу для человека прогоняй через скилл `natural-text` перед выдачей: живой каталог правок
  владельца, запрет длинного тире, живой русский.
- Утверждение в доке должно быть проверяемым. Если пишешь «автоматически подхватывается»,
  сначала проверь, что механизм существует, а не подразумевается.
- Устаревшее помечай явно (retired, дата, замена), а не оставляй как живое.
