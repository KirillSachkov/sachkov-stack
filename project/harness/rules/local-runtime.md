# Общий локальный рантайм

Git-worktree изолирует файлы, но не Docker, не занятые порты, не именованные тома, не базы,
не брокеры и не память машины. Эти ресурсы общие для всех агентов на хосте.

- Один тяжёлый локальный стек на проект на хост, с одним активным владельцем.
- До запуска, пересборки, рестарта, остановки, применения миграций и любых
  state-mutating интеграционных проверок посмотри, что уже запущено, и кто владелец.
- Не останавливай, не пересобирай, не делай `down`, не удаляй тома и не подменяй чужой стек.
  Переиспользование только через явный handoff.
- Второй стек через смену project name или портов не заводить: это обход правила, а не
  изоляция.
- Пока ждёшь, продолжай проверки, не требующие рантайма: статический анализ, юнит-тесты,
  сборку без Docker, ревью. Запиши точную отложенную команду и того, кто держит стек.
- Отложенная интеграционная проверка означает `verification pending`, а не `done`.
