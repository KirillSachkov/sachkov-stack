# Команды, которые pre-bash-guard блокирует в этом репозитории.
# Формат: <расширенная регулярка>|##|<причина>
# Строка без `|##|` даёт причину по умолчанию. Пустые строки и `#` игнорируются.
#
# Это базовый набор из пакета харнеса. Проектные запреты дописывай ниже своим блоком:
# файл целиком помечен в harness.lock как generated, поэтому правки переводи в customized
# (`harness-update` тогда не будет их затирать).

git\s+push\s+(--force|-f)(\s|$)|##|форс-пуш запрещён: перепиши историю локально и согласуй с владельцем
git\s+reset\s+--hard|##|hard-reset уничтожает несохранённую работу; используй git stash или git restore
git\s+clean\s+-[a-z]*f|##|git clean удаляет неотслеживаемые файлы безвозвратно
git\s+branch\s+-D(\s|$)|##|принудительное удаление ветки; используй -d или согласуй
docker\s+.*\bdown\b.*\s-v|##|down -v сносит тома вместе с данными общего рантайма
docker\s+volume\s+(rm|prune)|##|удаление томов затрагивает общий локальный рантайм
docker\s+system\s+prune.*--volumes|##|prune с томами сносит данные других задач
rm\s+-rf\s+/(\s|$)|##|удаление корня
rm\s+-rf\s+~(/\*)?(\s|$)|##|удаление домашнего каталога
